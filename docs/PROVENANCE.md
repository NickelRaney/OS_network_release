# Source selection and scientific provenance

## Evidence used

The original `OS_network` checkout was at commit `9f8a3d9` (2025-04-17), with
many tracked modifications and untracked experiments. That commit does not
describe all selected files. The release was assembled from the current
working-copy files on 2026-11-23; original content hashes and relative source
locations are recorded in `source_inventory.json`. No original file was edited.

The fixed main network is from
`OS_network/25_9_28/10_13/10_25 version of parameter for new model.mat`.
Its SHA-256 matches the snapshot identified by the 2026-10-05 MATLAB/native
benchmark and the 2026-10-28 historical onset audit. The later paper-figure
builder `2026_1_7_paperfigure/revised/fig5_icell_generate_data.m` also identifies
this snapshot and the separate
`25_9_28/lowlgn/low lgn full param.mat` as the saved final parameter sources.
The initial package included only the high-cx/Disordered-LGN network. At the
author's subsequent request the separate Low-LGN snapshot was also extracted,
without modifying either original archive. It is packaged as `data/low_lgn.mat`.
These sources establish the selected network realizations, not the exact historical
runtime source or random stream for all paper results.

The actual working-copy chain in `stat_script.m`, `suddeninput.m` and
`suddeninput_multi.m` is:

```text
fixed snapshot + spatial profile + pos_gen
    -> LGN3 (direct/BG) or LGN4 (global onset)
    -> NLIF, independently for 110 LGN afferents
    -> ex_gen2 or ex_gen_onset_test
    -> V1_4_fast (pure MATLAB)
    -> full-network spike trains and traces
```

`lgnout` and `pos_gen` were local functions in the historical scripts. Their
expressions have been extracted into ordinary functions. `V1_4`, `V1_5`, test
variants and the recent native simulator are not the selected runtime.

## Model configurations and disk control

`high_cx` uses the selected fixed network and the values listed as
"New model" in `25_9_28/parameters.txt`: F1 scale 2.25/1.5 and initial LGN
gain 1.15/1.20 for BG/direct grating. The author explicitly confirmed F1
2.25/1.5 for this model on 2026-11-23. The F1 curve starts at 1.13/1.10.
This is the release default. It is not proof that every saved historical
paper result was generated by those values.

Onset is a separate input protocol: the actual `suddeninput` call chain uses
`ex_gen_onset_test`, with initial E/I gains 1.11/1.15 and 20-spike curves.
These values are also identified in the 2026-09-19 SI numerical audit alongside
the author's corrected F1 coefficients. They are preserved rather than
automatically rescaled from the BG/direct-grating constants.

`low_lgn` loads `25_9_28/lowlgn/low lgn full param.mat` and uses the
Low-LGN values in `25_9_28/parameters.txt`: F1 scales 1.3/1.2 and initial
BG/grating LGN gains 1.11/1.15. Its onset input uses the original
`ex_gen_onset_test` curves with the same initial gains. The F1 scales match
the original working-copy simulator without changing its literals.
The distinct E-to-E connectivity, LGN wiring and saved L6/F2 parameters are
retained from this snapshot. See [Low-LGN details](LOW_LGN.md).

`historical_disk` combines the same high-cx network with literal working-copy
F1 scales 1.3/1.2 and initial steady LGN gains 1.11/1.15. It exists only for
source-equivalence checks, is not the published high-cx setting, and is not
the Low-LGN network. It remains a diagnostic control, not a third model.

F1 scales are not the base connection weights `param_v1.see` and `sie`.
The saved network weights, connectivity, F2 lookup tables, initial voltages,
refractory periods and other numerical fields remain unchanged. Runtime
overrides are duration, onset, input position, explicit gain settings and
the optional kernel delay. The archived `param.duration=7` is overridden to
match the requested V1 duration.

## Release changes to historical source

- `V1_4_fast`: optional `f1_ee_scale` / `f1_ei_scale` fields replace two literal
  constants. Missing fields use the confirmed 2.25/1.5. The verification control
  explicitly passes 1.3/1.2. No update order, equations,
  random draws, thresholds, adaptation or synaptic-delivery rules were changed.
- `ex_gen2`: optional initial E/I LGN gains. Its original fixed subsequent
  stages (E 1.12 then 1; I 1.05 then 1), trigger inequalities and flags remain.
  Later experiments' different gain schedules are not imported.
- `ex_gen_onset_test`: the public function name now matches the file name.
  Separate optional onset gains can rescale the original 20-spike curves
  about 1; all shipped configurations evaluate the original curves literally.
  BG/direct-grating initial gains do not affect this helper. Before onset the gains are fixed;
  only spikes strictly after onset advance the curve; after 20 spikes the gain
  is 1. Dead commented experiment blocks were removed from both generators.
- New wrappers expose existing local helpers, set/record seeds, enforce the
  audited sampling assumptions, save fresh results and summarize spikes.
  Original stochastic initialization of synaptic state is preserved even when
  saved `init_v1` voltages are supplied.

The source-comparison test checks both generators exactly and all eight V1
outputs plus the final RNG state against unmodified working-copy functions.
The original source files and released versions are distinguished by SHA-256.

## Historical reproduction limits

The 2026-10-28 audit in
`V1_padding20_first_test_20261008/results/onset_reproduction/20261028_old_parameters/conclusions.txt`
explicitly found only partial historical reproduction with the later native
simulator. The historical F1 source and original random seeds were unresolved.
This release does not promote that native experiment to a MATLAB reference.

Saved kernels have 16/25 leading zero samples (OFF/ON, 1 ms sampling). Historical
paper latencies received a separate +4 ms display shift. Adding four zero
samples to the kernels and shifting analysis values by four milliseconds are
different procedures in a stochastic recurrent network. The new simulation
examples do neither implicitly.

Historical complex onset data used 3 phases x 60 accepted trials. The original
trial rejection tested more than 500 ROI E spikes in a strict 15 ms open window
before onset (window starts 1200:1484 ms). New examples retain every trial and
do not implement that rejection protocol. The compact fixture retains only
histograms, category identities and archived latency references; it cannot
recover rejected trials, seed history or individual historical ISIs.

The historical t50 estimator uses a 21-point Gaussian (SD 5 ms), background
bins 1:1000, steady bins 1200:2000 (801 bins), and the first 26 consecutive
samples strictly above background plus half the steady increment. It searches
300 bins and uses 301 for no crossing, then chooses the fastest phase. The
literal 16.66 rate factor and original histogram edges are retained. The
historical +4 ms offset is applied only when displaying fixture summaries.

## Data transformation

For each model, `tools/extract_parameters.m` selects only `param`, `param_v1`, `init_v1`,
`kernel3`, `grid`, `Cat`, `Cat_i`, `LVwire`, `LVwire_i`, `inde`, and `indi`.
It round-trips each retained variable with `isequaln`. Saved external inputs,
simulation outputs and workspace handles are excluded. Values and MATLAB
classes are preserved, including logical connectivity matrices; no sparsifying
or rewiring of the fixed network occurs.

`tools/extract_onset_reference.py` reduces the previously audited
`legacy_matlab_reference.mat` to integer 1 ms counts for 247 complex cells,
3 phases, their original T50 values and cell/category metadata. Replacing the
histograms with newly binned spikes is intentionally avoided because floating
point edge conventions can change individual threshold crossings.
